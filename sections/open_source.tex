\mysection{Open Source Contributions}

\mysubhead{\href{https://github.com/pypa/pip}{Python packaging --- pip and packaging}}

\begin{bullets}
    \item \blead{Candidate selection}replaced a linear scan of the supported tag list with a precomputed index lookup, cutting best-candidate selection 11x in profiling, from 68s to 6.2s over 30 calls (\href{https://github.com/pypa/pip/pull/9748}{pull request}).
    \item \blead{Tag equality}short-circuited tag comparison on a cached hash. Comparing tags accounted for two thirds of the time spent picking a candidate; it got 2.5x faster and nearly halved the operation overall (\href{https://github.com/pypa/packaging/pull/417}{pull request}).
\end{bullets}
Together these cut the time spent on pip steps in ci (at Kensho).

\mysubhead{\href{https://github.com/pantsbuild/pants/pulls?q=is\%3Apr+state\%3Amerged+author\%3Ajbylund}{Pants build system}}
Moved work that repeated per target, file or image into an index or memo built once per run (rust and python). Together the changes cut a cold \mbox{\texttt{pants peek ::}} on a monorepo of {\mytilde}65.8k targets from 118s to 77s (1.5x).

\mysubhead{\href{https://github.com/tobymao/sqlglot/pulls?q=is\%3Apr+state\%3Amerged+author\%3Ajbylund}{SQLGlot}}
Correctness fixes to the python SQL executor and optimizer, checked against duckdb, postgres, mysql and sqlite. Most notably, a subquery in a predicate or projection put SQL text into the generated python and failed with a syntax error; such subqueries are now planned once and run per outer row (\href{https://github.com/tobymao/sqlglot/pull/8190}{pull request}).

\mysubhead{\href{https://github.com/GNOME/shotwell/commits?author=jbylund}{Gnome Shotwell Photo Manager}}
Contributions from 2013 to 2026, across the import pipeline, thumbnail cache, saved searches, publishing plugins and build system (vala).
Recent work removes decoding the photo import repeated or threw away: each photo is decoded once for all its thumbnail sizes, and full-size JPEG decodes that were only read for their dimensions, or then discarded, are skipped, which took importing a test corpus of images from 21.5s to 13.3s (1.6x).

\mysubhead{\href{https://github.com/php/php-src}{PHP}}
Removed a per-column roundtrip to the database in PDO's PostgreSQL driver, resolving the common type OIDs directly instead of querying for each one (\href{https://github.com/php/php-src/commit/e10257ba8069fb982d9cd8681f6633de9fea534d}{commit}).
Shipped in PHP since 2015; the saving scales with the width of the result set, and at Moat it cut queries and page load time by more than an order of magnitude on the user administration pages.
