    \item \blead{Text search prefilter}the last unindexed text column was matched per row --- 52k string comparisons over only 26.3k distinct values --- and could never narrow, so a single such predicate voided OR narrowing for an entire query. Resolved it once against the distinct values behind a 128-bit n-gram signature rejecting 97\% of candidates, then expanded matches back to rows through a CSR inverted index: 15x on a bare predicate and 8x on the OR combination that motivated the work, for {\mytilde}1MB of index against 5--9MB for a trigram alternative (rust, \href{https://github.com/jbylund/sylvan_librarian/pull/622}{pull request}).
